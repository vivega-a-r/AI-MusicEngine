# AI USE DISCLOSURE

## 1. Overview
In accordance with the transparency requirements of the IncuBrix Engineering Assessment, this document discloses the artificial intelligence assistance utilized in the architecture, implementation, and verification of **IncuBrix Music Studio**.

---

## 2. AI Tools Utilized
- **AI Coding Assistant**: Google DeepMind Antigravity AI Coding Assistant (Gemini 3.8 Flash High).
- **Environment**: Antigravity IDE pairing environment with local terminal execution, file editing, and testing capabilities.

---

## 3. Scope of AI Involvement

| Domain | AI Contribution | Human/Engineering Oversight |
|---|---|---|
| **Architecture & System Design** | Generated the modular monorepo structure, API v1 routing schema, and data contracts. | Defined the strict zero-cost non-negotiables, stem separation criteria, and broadcast loudness specs. |
| **Procedural Composition Engine** | Generated the music theory algorithms in Python (scales, chord progression templates, Roman numeral degree mappings, section timelines). | Verified voice leading, cadence resolution, and determinism across random seeds. |
| **Vectorized Sound Synthesizer** | Implemented NumPy and SciPy algorithms for Karplus-Strong string synthesis, logarithmic pitch-drop drum synthesis, and ADSR envelopes. | Verified 48 kHz sample rate, -1.0 dBTP true-peak ceiling, and lack of clipping artifacts. |
| **Audio Mastering & Voiceover Ducking** | Wrote signal processing routines for speech envelope detection and ITU-R BS.1770 LUFS normalization via `pyloudnorm`. | Confirmed zero pumping artifacts and tested edge cases with long speech silences. |
| **Frontend Implementation** | Scaffolded Vite React TypeScript components, Tailwind CSS dark SaaS aesthetic, multi-track mixer, and canvas visualizer. | Verified responsiveness, strict TypeScript compilation (`verbatimModuleSyntax`), and user experience flows. |
| **Automated Testing Suite** | Implemented 24 comprehensive `pytest` cases and the 10-prompt batch runner. | Executed and validated all 24 tests on Windows Python 3.12, achieving 100% pass rates. |

---

## 4. Distinction Between AI in Code Generation vs. AI in Product Output
- **Code Generation**: The software code was developed collaboratively with the Antigravity AI assistant.
- **Product Audio Output**: The music generated by IncuBrix Music Studio is produced by a **deterministic, procedural rule-based composition and DSP synthesis engine** running locally on the user's CPU. The application explicitly labels all output as **Procedural AI Music Composition** and never misleads creators into believing an external cloud neural model was used when the composition is algorithmic.
